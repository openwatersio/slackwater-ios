1.6.0 (30)

This release makes the next useful tide detail easier to see, from the Home Screen to the station page.

· The medium Home Screen widget is now a mini tide scrubber, with the current point, the day’s curve, and the next high or low tide together at a glance.
· Tide station pages now keep location, datum, source, and model details close at hand in a compact section you can expand when needed.
· Rapid-current gates include clearer sourced context about the expected current strength.
· Offline setup now downloads the data shown on the first screen, and coastlines no longer show stray seams at map-tile edges.

Worth testing: add the medium widget, compare its current point and next event with the same station in the app, then expand the station details. Tell us what still feels missing when you check the tide quickly.
