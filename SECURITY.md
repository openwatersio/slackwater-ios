# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues.

Use [GitHub private vulnerability reporting](https://github.com/openwatersio/slackwater-ios/security/advisories/new), or email [slackwater@openwaters.io](mailto:slackwater@openwaters.io) with enough detail to reproduce the problem.

You should hear back within a week. Once a fix ships, we will credit you in the advisory unless you prefer otherwise.

## Scope

Slackwater runs its predictions on the device and holds no user accounts or server-side user data. The most valuable reports are anything that lets a crafted network response, shared link, or bundled data file execute code, corrupt state, or exfiltrate data from the app.

A wrong tide or current prediction is a serious bug, but not a security vulnerability — please [open a regular issue](https://github.com/openwatersio/slackwater-ios/issues/new?template=bug_report.yml) for those.
